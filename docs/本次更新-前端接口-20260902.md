# 前端接口变更（极简）

前缀：`/sjxy-console/secops/api/secops/v2`

---

## 1. 补丁安装向导：受影响包

`POST /patch/affected-pkgs`

**必须改传参**（不传主机，向导仍会同时列出 x86_64 和 aarch64 的包）：

```json
{"patch_ids": ["KYSA-202409-1017"], "host_ids": ["<第1步已选主机ID>"]}
```

单台也可用 `"host_id": "..."`。URL / 方法 / 权限不变。

**响应仍是数组，`file_name` 还在。** 带主机时多三个字段：

| 字段 | 说明 |
| --- | --- |
| `file_name` | 要升到的目标包（无 `.rpm` 后缀） |
| `installed_pkg` | 该主机当前已装版本，可渲染成 `installed_pkg → file_name` |
| `pkg_name` | 包名 |
| `patch_id` | 公告号 |

口径：只返回**与该主机架构一致、且本机已装、版本低于公告**的包。  
多台主机时按 `file_name` 并集；各台已装版本不一致则不返回 `installed_pkg`（只显示 `file_name`）。  
没有主机上下文的页面（补丁详情）不用改。

## 2. 全量软件包库：OS 版本

依赖库表加了 `os_version` 列（现场需执行 V16）。

### 列表：新增筛选，ubuntu 不再折叠

`GET /rpm-info/list`

- 新增可选参数 `osVersion`（取值来自下面枚举接口）
- 每行新增字段 `osVersion`（推不出来为 `null`，显示「未知」）
- **ubuntu 同一包 20.04 / 22.04 / 24.04 各占一行**，不再折成一条。不带筛选时 ubuntu 总数大约 ×3
- 其余参数 `source` / `keyword` / `name` / `arch` / `page` / `size` 不变

### 新增：OS 版本下拉

`GET /rpm-info/os-versions?source=`

`source` 可选。返回与 `/rpm-info/architectures` 同形：

```json
{"total": 3, "content": ["20.04", "22.04", "24.04"]}
```

kylin 一般为 `V10`，redhat/oracle 为 `8`，suse 为 `15`。

### 详情 / 批量详情

`GET /rpm-info/detail/{id}`、`GET /rpm-info/detail`、`POST /rpm-info/batch-detail`  
响应多一个 `osVersion`，老字段不动。
