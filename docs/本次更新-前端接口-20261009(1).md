# 前端接口变更（20261009）

前缀：`/sjxy-console/secops`（第 2 节为 `/sjxy-console/cmdb`）

---

## 1. 单机补丁列表：新增「仓库可安装」列

`GET /api/secops/dashboard/patch-of-one-machine`（参数不变）

每行新增 `repo_check`：

```json
"repo_check": {
  "status": "NOT_INSTALLABLE",
  "label": "不可安装",
  "missingPkgs": ["xxx"],
  "outdatedPkgs": [{"pkgName": "libxml2", "requiredVersion": "2.9.10-43.p16.ky10", "repoVersion": "2.9.10-43.p12.ky10"}]
}
```

| status | 展示 |
| --- | --- |
| `INSTALLABLE` | 可安装 |
| `NOT_INSTALLABLE` | 缺失：`missingPkgs`；版本过低：`pkgName`（需 `requiredVersion`，仓库 `repoVersion`） |
| `NO_REPO` | 直接显示 `label`（未匹配到本机所属仓库 / 所属仓库尚未采集成功） |

`repo_check` 为 `null` 时显示「-」。

## 2. CMDB 导入模板：按网段自动划分网络区域

模板（`GET /api/cmdb/cit/template2/{tenantId}`）新增一个 sheet「网段区域」，两列：

| 网段 | 网络区域 |
| --- | --- |
| 10.1.0.0/16 | 内网环境 |
| 192.168.2.* | 外联网 |

- 网络区域是下拉框，只能从 `互联网`、`外联网`、`内网环境、孤岛环境` 中选一个。
- 每台主机只会有一个区域：导入时会先去掉原来的区域，再打上新的。
- 一台主机命中多条网段时，取最精确的那条。同一网段填了不同区域时会报错，以先出现的那行为准。

**前端无改动。**

## 3. 变更回滚 / 安装历史：按包安装的记录显示补丁号和漏洞号

| 字段 | 原来 | 现在 |
| --- | --- | --- |
| `patch_id`（修复补丁编号） | `packages` | `KYSA-202503-1125` |
| `update_id`（更新维度） | `packages` | `CVE-2024-30205,CVE-2024-39331,CVE-2025-1244` |

**前端要改：** 按包安装的记录，`update_id` 可能是用逗号分隔的多个 CVE，需要按逗号拆成多个标签展示，每个标签各自链接到对应的漏洞。不属于任何补丁的包（例如新装的 nginx）仍然显示 `packages`。

## 4. 新增：安装任务失败主机

`GET /api/secops/v2/patch/task/{id}/failed-hosts`

```json
{
  "taskId": "c0RpuRCo2sGIWbmABaR5",
  "taskType": "pkg_update",
  "status": "PRE_CHECK_DONE",
  "preCheckFailed": [{"hostId": "4dXya7C2HjUWfws2ygs4", "hostKey": "192.168.1.235", "reason": "主机无法连通（SSH 不可达）..."}],
  "installFailed":  [{"hostId": "...", "hostKey": "...", "reason": "..."}],
  "failedHostIds": ["4dXya7C2HjUWfws2ygs4"]
}
```

- `preCheckFailed`：预检失败的主机。
- `installFailed`：安装失败的主机。
- `failedHostIds`：两类失败主机去重后的合集，可直接用于重新发起安装。
- 任务不存在时返回 404。

建议在任务列表加一个「失败主机」入口，用两张表分别展示两类主机。

## 5. 新增：中间件 CVE 受影响主机

`GET /api/secops/v2/middleware-cve/affected-hosts?cveId=CVE-2022-41742&middlewareType=nginx`

`middlewareType` 可选。返回数组：

```json
[{
  "hostId": "h16tFTPByvJkqGa81n0V",
  "hostKey": "192.168.1.236",
  "middlewareType": "nginx",
  "pkgName": "nginx",
  "installedVersion": "1.21.5",
  "installedPkg": "nginx-1.21.5-2.p13.ky10.x86_64.rpm",
  "affectedRange": "f5:nginx (>=1.1.3, <=1.22.0)",
  "fixedVersion": "",
  "osScanStatus": null
}]
```

`osScanStatus` 是该 CVE 在 OS 补丁扫描中的状态，可用来交叉确认，没有时为 `null`。在 CVE 列表或详情里加「受影响主机」即可。
