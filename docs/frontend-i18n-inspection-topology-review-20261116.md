## 响应性与协议边界

- KPI 的展示名使用 getter；`pageParam`、排序、图标和原始数值保持。已打开的标题和持续错误保存消息 key 与参数，语言切换时重新求值。
- 切换语言不重新读取任务、图数据或任何详情，不重置搜索草稿、二级业务 Tab、详情开关或列表数据。读取中的结果继续按原报告/窗口上下文判断是否接纳。

- 状态 `OK/FAILED/CHECK/SKIPPING/UNREACHABLE`、八类 KPI 参数、原始报告 ID、分隔符协议和返回列表 query 保持；未知状态仍按后端原文展示。
- 数量使用包含命名参数的完整消息和英文单复数分支；一级业务统计的数字通过 `I18nT` 插槽保留原强调样式。仅增加部分较长英文表头与操作列的最小宽度。
- PNG 下载仍使用原 `getDataURL` 参数；Excel 仍使用原 GET 地址、认证头和 blob；已有后端报告名继续用于文件名，只有前端默认名翻译。未生成截图或执行浏览器视觉 QA。

## 图展开状态的处理

真实 ECharts 回归确认，仅 `setOption({ toolbox })` 也会重建树数据，从而丢失运行时展开状态。为保留用户操作，本批使用公开 `treeExpandAndCollapse` 事件记录相对于初始图的展开变化，工具栏翻译更新后通过公开动作批量重放。

重放期间不再次记录同一动作；用户点击还原或加载新图时清空记录。语言变化不重新绑定事件、不替换传入的后端节点，也不调用原完整绘图函数。真实引擎测试覆盖连续切换语言、已改变的展开状态、缩放值和还原后的再次切换。测试使用无界面 SVG 模式，仅检查模型状态，不写入截图文件。
