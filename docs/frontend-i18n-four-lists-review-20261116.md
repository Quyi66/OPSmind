# 四个在用列表页面的英文布局修复

- 分支：`feature/frontend-i18n`；本轮基线：`b5a89207`。
- 依据：用户提供的运维工具、设备清单、Windows KB 知识库、Linux 变更回滚四张实际截图。
- 本轮只处理这些在用菜单页面的英文布局，中文默认结构、列宽、样式及断点保留。

## 修改与入口

| 在用入口 | 截图中的问题 | 本轮实现 |
| --- | --- | --- |
| `/jao/jobs` → `JobListPage.vue` | 英文日期的 AM/PM 被挤到下一行，修改人表头过窄，类型图标与文字紧贴，长操作挤压 | 英文时间列从 180px 增至 240px，保持完整日期格式并禁止时间单元格内换行；修改人、类型及操作列分别增宽；类型标签和操作栏增加图文间距，行内动作采用明确间距。搜索框只在英文增加宽度 |
| `/acm/info` → `AssetInfoPage.vue` | No reboot required、Reboot required 被截断，系统名称空间不足 | 英文重启建议固定列宽为 188px、系统环境最小列宽为 240px；提示和系统名称支持按词换行，系统图标不被压缩，长名称容器允许收缩 |
| `/patches/windowsKbList` → `WindowsKbListPage.vue` | 严重程度标签和数字在小卡中重叠，说明长文案受单行约束 | 英文严重程度名称与数量分行，数量与百分比保留独立节点，并按可用宽度换列；卡片标题/说明/修复状态支持换行；调整英文严重程度、最高 CVSS、发布日期列及关键词输入宽度 |
| `/patches/changeRollback` → `LinuxPatchRollbackPage.vue` | 补丁 ID 表头与内容空间不足，软件版本和箭头交错换行，回滚/删除按钮堆叠 | 英文补丁 ID、软件版本及操作列增宽；旧版本、箭头、新版本采用三列排列，长版本可折行；行内动作使用明确间距。展开的软件版本浮层同步应用英文排列 |

所有布局规则通过组件根部 `.is-english` 或浮层自身的英文标记启用。表格新增的单元格 class 只在英文下设置。保留原有日期格式、时区语义、排序、筛选、分页、勾选、API 状态及事件；没有通过改成 24 小时制、删除日期信息或缩短业务字段来适配列宽。

截图中的工具标题、描述、资产类型、主机/系统名称、KB 标题、包版本和其他后端原文保持，未当作本地界面语言进行猜测翻译。没有修改词库、菜单结构、权限或接口。

| 检查 | 结果 |
| --- | --- |
| 中文 CSS 基线 | 4 个组件的 scoped 与非 scoped 样式分别编译，排除英文规则后，与 `b5a89207` 的选择器、声明、顺序及媒体规则一致。JobList 的既有 `@use` 使用项目 styles 目录解析；原公共样式导入和全局样式保持 |
| 中文模板基线 | 将模板 AST 中英文条件关闭，归一注释、空白、未启用 class 和绑定后，4 个组件均与基线一致，本轮无额外中文布局例外 |
| 新增测试 | 每页各 1 项，共 4 项；验证日期显示与原始时间、实际资产表格实例/勾选、KB 统计数值及 `Important` 原始筛选值，以及回滚记录/包版本/目标在语言往返中保持 |
| 定向回归 | 资产模块、运维工具交互、Windows 知识库、Linux 安装/回滚/概览、公共导航、语言服务、路由/缓存、标签和权限策略共 **41 个文件、294 项用例通过**，无失败或跳过 |
| 静态检查 | 4 个 Vue 的脚本、模板及 SCSS 编译通过；8 个脚本/组件/测试文件相对基线无新增 ESLint 错误，13 条既有错误保持 |
| 接口审查 | 4 个生产组件的 20 处 API 调用及实参 AST 与基线一致 |
| 资源与差异 | 中英文仍各 5003 个词条；key、参数、消息语法及 8022 处源码字面量引用检查通过，`git diff --check` 通过 |

表格列宽按语言恢复原声明类型：原来的固定列仍为固定列，原来的最小列宽仍为最小列宽。语言切换不重新查询、不提交运行/删除/回滚任务；相关真实表格与原始目标的既有交互测试一起回归。

## 审查与验收边界

本轮独立提交；增量和本地审查资料位于 `.cache/i18n-four-lists-review.patch`、`-review-files.json`、`-review-status.json`。基线文件和哈希保存在 `-start/`，中文保护结果在 `-scope.json`，静态和接口结果在 `-static-results.json`、`-api-audit.json`。`.cache/i18n-windows-four-lists-final.json` 及 `.log` 保存本轮回归结果。

本轮依据用户提供的实际截图定位，没有新读取浏览器页面，也没有执行生产构建。静态 CSS/模板比对和 jsdom 交互测试不等于真实几何排版验收；浏览器连接恢复后，仍需在实际窗口中复核横向滚动、长软件版本、数字极值、输入控件和弹出浮层。

已注册但没有菜单且没有实际调用的功能继续暂缓，不扩大到整个目录的历史页面。
