# 仪表盘重新设计文档

## 概述

根据提供的设计效果图，我们完全重新设计了OpsMind的首页仪表盘，采用了现代化的布局和丰富的数据可视化组件。

## 新功能特性

### 1. 左侧边栏 (DashboardSidebar)
- **欢迎信息区域**: 显示用户头像、欢迎语和当前日期
- **我的待办**: 显示系统通知和待处理事项，支持优先级标识
- **最近使用**: 网格布局显示最近使用的功能模块

### 2. 软件概览 (SoftwareOverview)
- 四个关键指标卡片：日执行数、失败数、资产数、告警数
- 每个卡片都有独特的颜色主题和图标
- 支持点击交互和悬停效果

### 3. 作业概览 (JobOverview)
- 作业统计数据：REST作业、命令作业、脚本作业
- 近10天作业数据的柱状图可视化
- 使用ECharts实现交互式图表

### 4. 巡检概览 (InspectionOverview)
- 巡检统计：本月巡检次数、正常、异常
- 近10天巡检结果情况的柱状图
- 正常/异常状态的对比展示

### 5. 资产概览 (AssetOverview)
- 不同操作系统的资产分布
- 横向条形图展示Linux、Unix、Windows系统
- 支持平台切换（企业版/社区版）

### 6. 漏洞概览 (VulnerabilityOverview)
- 漏洞严重程度分布饼图
- 严重、高危、中危、低危四个级别
- 详细的统计列表和百分比显示

## 技术实现

### 依赖库
- **Vue 3**: 前端框架
- **Element Plus**: UI组件库
- **ECharts**: 图表可视化库
- **Vue-ECharts**: Vue的ECharts封装
- **SCSS**: 样式预处理器

### 组件结构
```
src/components/
├── DashboardSidebar.vue      # 左侧边栏
├── SoftwareOverview.vue      # 软件概览
├── JobOverview.vue           # 作业概览
├── InspectionOverview.vue    # 巡检概览
├── AssetOverview.vue         # 资产概览
└── VulnerabilityOverview.vue # 漏洞概览
```

### 响应式设计
- **桌面端**: 左侧边栏 + 主内容区域的两栏布局
- **平板端**: 概览组件改为单列布局
- **移动端**: 左侧边栏移至底部，所有组件单列显示

## 使用方法

1. 启动开发服务器：
```bash
npm run dev
```

2. 访问仪表盘：
```
http://localhost:5174/ops/
```

3. 所有组件都支持交互，点击可查看详情（目前显示提示消息）

## 问题修复记录

### 修复1: 左侧边栏加载时序问题
- **问题**: 左侧边栏先于主内容区域显示
- **解决方案**: 将加载状态提升到整个页面级别，确保所有内容同时显示

### 修复2: 组件重叠问题
- **问题**: 作业概览与资产概览重叠，巡检概览与漏洞概览重叠
- **解决方案**:
  - 将Grid布局改为Flexbox布局
  - 为每个组件容器添加独立的类名
  - 设置固定高度和overflow: hidden
  - 添加position: relative确保正确定位

### 布局优化
- 调整组件间距和内边距
- 优化响应式断点
- 确保每个概览组件都是独立的卡片

### 修复3: 页面高度比例优化
- **问题**: 需要确保页面垂直方向按1/3比例分配
- **解决方案**:
  - 顶部1/3: 软件概览区域
  - 中间1/3: 作业概览 + 巡检概览 (左右平分)
  - 底部1/3: 资产概览 + 漏洞概览 (左右平分)
  - 使用flex: 1实现等高分配
  - 响应式设计在小屏幕上自动调整

### 📱 当前布局结构
```
Dashboard (100vh)
├── 左侧边栏 (固定宽度280px, 100vh)
└── 主内容区域 (垂直三等分布局)
    ├── 软件概览 (1/3高度)
    ├── 中间区域 (1/3高度, Flexbox 1:1)
    │   ├── 作业概览
    │   └── 巡检概览
    └── 底部区域 (1/3高度, Flexbox 1:1)
```
