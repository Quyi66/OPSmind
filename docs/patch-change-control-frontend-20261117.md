# 变更管控、补丁审批与安装后巡检前端接入

依据[中信国际前端接口文档](./中信国际-变更窗口审批巡检英文-前端接口文档-20261112.md)，在 `feature/frontend-i18n` 的 `29ec9e64` 上接入后端 `boc-3.10.9` 契约。请求继续使用已有 console 网关和认证。

## 页面与行为

| 在用入口 | 变更 |
| --- | --- |
| 补丁管理 → 安装申请 | 管理员可在「变更管控」查看和保存窗口、判定时区、工作时间、非工作时间策略及审批开关。支持每周和指定日期范围窗口。 |
| Linux 安装、回滚、软件包更新和漏洞修复向导 | 提交前可填实施起止时间与申请说明。待审批任务显示申请入口。获批的普通安装申请按实施计划由后端自动执行，详情查看进度。 |
| 包集安装及补丁定时安装 | 计划执行时间作为窗口预判的起始；可填实施结束时间及申请说明。创建请求保留 `scheduledTime`，不重复提交 `planStartTime`。 |
| Windows 安装及回滚向导 | 共用变更窗口预判与审批。待审批任务等待管理员处理，获批的普通安装申请在详情查看进度。 |
| 安装申请和详情 | 显示实施时段、申请说明、窗口判定和非窗口复核标记。管理员批准 Linux 任务时可通过设备选择器预设巡检主机，审批过期由计划时间和结束时间共同判断。 |
| Linux 向导执行页及申请详情 | 任务进入后端允许巡检的状态时提供「系统巡检」。读取审批预设及任务主机，可重复发起巡检，运行时每 7 秒轮询，关闭后停止。管理员可补充 Linux 主机 IP。 |
| 补丁流程操作记录 | 审计详情返回 `INSPECT` 时显示巡检步骤及其状态。 |

## 接口与语言

- 五个创建接口先调用 `change-control/check`。`PASS` 继续，`REJECT` 展示后端原因，`CONFIRM` 使用返回的短语。创建或执行接口返回 `NON_WINDOW_CONFIRM_REQUIRED` 时复核并重试同一个请求，保留原始用户输入。普通 400 提示保留后端原文。旧服务明确返回 404 或 405 时由创建接口做最终校验。
- 用户填写的实施时间按 Asia/Shanghai 转为毫秒时间戳。定时安装保持原有服务端时区字符串。审批的到期、预判和请求使用同一时区解释。
- 安装、回滚和真正的重启执行接入窗口复核。预检查、校验和跳过调用保留。Linux 流程识别预检查后已自动进入安装或回滚的状态，避免重新下发同一步。
- Axios 公共请求发送 `Language: zh-CN` 或 `Language: en`。初始化和切换语言同步同源 `NG_TRANSLATE_LANG_KEY` Cookie，供同源下载等非 Axios 请求使用。前端注册表继续启用简中和英文，并保留扩展字段。
- 已知任务状态、类型、窗口结果、审计键和巡检状态从后端语言包读取，中文静态动作通过后端字典反查；前端自有控件由现有中英文资源负责。用户申请说明、历史日志正文、巡检风险、原始主机名称及字典插值原样保留。漏洞界面的着色和操作条件优先读稳定状态字段。

## 2026-11-18 审查修复

- 跳过预检查在打开确认框前锁定任务 ID 和安装或回滚类型。切换任务、关闭或卸载详情后，旧操作停止发起后续请求。执行接口共用该保护，旧响应也无法更新新任务或解除其操作锁。重试预检查和手动步骤复用同一上下文。
- 删除语言 Cookie 的重复异常捕获和变更窗口的重复决策校验。复核短语继续按接口约定校验和提交。审批时间戳 `0` 的含义待后端确认。
- 5 个定向测试文件共 25 项通过。新增模拟用例覆盖确认期间切换、跳过请求在途时关闭重开、旧执行响应和同一回滚任务执行。定向 ESLint、词库及 Git 差异检查通过。

## 2026-11-18 界面调整

- 「安装申请」工具栏左侧的首个按钮为管理员可见的「变更管控」蓝色主按钮。弹窗按管控设置、工作时间和变更窗口分组，每条规则有独立的类型、时间和删除操作。
- 工作时间和每周窗口通过时分控件选择起止时间。「当日结束（24:00）」提交接口约定的 `24:00`，继续支持跨午夜和起止相同表示全天。指定日期范围使用日期时间选择器，兼容已有的分钟和秒两种精度。
- 「平台用户管理 → 用户列表」的中英文操作列分别固定为 176px 和 208px，「平台用户管理 → 补丁分配」分别固定为 152px 和 252px。操作顺序保留，数据列可使用释放的空间。
- 安装、回滚及定时安装共用的「实施计划」把时区说明置于标题下方，起止时间在宽布局并排，申请说明改为单独的多行输入。定时安装仍从原来的执行时间取得计划开始时间。
- 9 个定向测试文件共 101 项通过。时间控件测试使用模拟配置接口，两套词库各 5087 条消息，词库和 Git 差异检查通过。两张平台用户页面共 5 条 ESLint 报错与修改前一致，其他改动源码和测试通过定向 ESLint。

### 首个页签与判定时区复查

- 顶部页签栏和模块侧栏共用宽度与间距，修复英文展开侧栏遮挡左箭头及首个页签的问题。专用 Chrome 在 1440px 视口验证了中英文各自的侧栏展开、折叠状态，并检查了左箭头和首个页签的命中区域。
- 「判定时区」改用可搜索的下拉选择，提供常用时区及浏览器支持的时区。服务端已配置的时区会出现在选项中，即使它属于旧别名。中英文真实页面均搜索并选中 `Asia/Hong_Kong` 后取消，模拟接口覆盖已有时区回显和选择后的提交值。
- 4 个定向测试文件共 11 项通过。词库及 Git 差异检查通过。布局组件的 3 条 ESLint 报错与修改前一致。

### 安装申请操作列与失败主机入口

- 安装申请和 Linux 安装向导共用任务状态判断，仅在进入预检查或后续执行阶段后提供「失败主机」入口。待审批、待执行、驳回和过期状态隐藏该入口。
- 安装申请操作列按当前页实际可用操作收窄。专用 Chrome 在 1440px 视口复查了一条真实待审批记录。中文列宽 136px，显示「详情、通过、驳回」。英文列宽 128px，审批操作位于 More 菜单。两种语言都未显示「失败主机」。
- 5 个定向测试文件共 34 项通过。向导通过模拟任务状态覆盖普通用户提交后的按钮显示，以及预检查失败和执行完成后的入口。本次真实页面检查只查看待审批记录。

### 流程操作记录与双语按钮一致性

- 「流程操作记录」的操作列按当前页可用按钮设定宽度。有失败主机入口时，中文由 170px 收窄至 128px，英文为 160px。仅有详情时分别为 72px 和 88px。待审批和待执行记录沿用安装申请的状态判断，隐藏失败主机入口。
- 「安装申请」中英文共用同一套行内操作。待审批时，管理员直接看到「详情、通过、驳回」或「Details、Approve、Reject」，列宽分别为 136px 和 184px。切换语言复用同一记录和审批条件。
- 专用 Chrome 在 1440px 和 1920px 视口中检查了一条待审批申请及 20 条流程记录。两种语言的按钮均在各自操作列内单行显示。4 个定向测试文件共 32 项通过，覆盖语言切换、审批权限、到期限制及失败主机入口。

### 审批时选择预设巡检主机

- 管理员批准 Linux 任务时可在设备选择器中多选主机，选中的设备回填审批弹窗。确认审批时按 `inspectionHostIds` 提交去重后的资产 ID。该字段可留空。Windows 审批和驳回流程只提供审批意见。
- 在专用 Chrome 的中英文页面分别选中两台真实设备，核对回填后取消审批。16 项定向测试通过，覆盖选择结果的提交值、取消后重新打开、留空、Windows 审批和驳回。审批请求通过模拟接口验证。

### 普通安装申请获批后按实施计划自动执行

- 2026-11-18 确认普通用户的安装申请获批后由后端按实施计划自动执行。本规则替代 2026-11-12 原接口文档第 2.4 节对该流程的手动续执行描述。实施计划使用 `planStartTime` 和 `planEndTime`，`scheduledTime` 用于定时安装。
- 申请详情根据后端返回的审批信息识别获批的普通安装申请，显示等待实施提示和轮询到的任务状态。预检查、跳过、执行安装、重启和校验均不提供手动入口。执行结果与巡检仍可按原有条件打开。
- 审批弹窗把普通申请的实施时间显示为「实施计划」，列表和详情仅在有定时安装数据时显示「计划执行时间」。审批接口继续提交原有审批字段。
- 5 个定向测试文件共 42 项通过。模拟接口验证了从待审批到执行中的轮询、手动入口的显示条件、原审批请求和定时任务的轮询时机。
- 当前仓库包含前端实现。自动下发、实施时段校验和后续任务状态由补丁服务负责，真实后端按时执行需联调确认。
