# 变更管控、补丁审批与安装后巡检前端接入

依据[中信国际前端接口文档](./中信国际-变更窗口审批巡检英文-前端接口文档-20261112.md)，在 `feature/frontend-i18n` 的 `29ec9e64` 上接入后端 `boc-3.10.9` 契约。请求继续使用已有 console 网关和认证。

## 页面与行为

| 在用入口 | 变更 |
| --- | --- |
| 补丁管理 → 安装申请 | 管理员可在「变更管控」查看和保存窗口、判定时区、工作时间、非工作时间策略及审批开关。支持每周和指定日期范围窗口。 |
| Linux 安装、回滚、软件包更新和漏洞修复向导 | 提交前可填实施起止时间与申请说明。待审批任务显示申请入口，审批通过后从任务详情继续对应步骤。 |
| 包集安装及补丁定时安装 | 计划执行时间作为窗口预判的起始；可填实施结束时间及申请说明。创建请求保留 `scheduledTime`，不重复提交 `planStartTime`。 |
| Windows 安装及回滚向导 | 共用变更窗口预判与审批。待审批任务不下发流程步骤；可从安装申请详情续执行。 |
| 安装申请和详情 | 显示实施时段、申请说明、窗口判定和非窗口复核标记。管理员批准 Linux 任务时可输入巡检资产 ID 或 IP，审批过期由计划时间和结束时间共同判断。 |
| Linux 向导执行页及申请详情 | 任务进入后端允许巡检的状态时提供「系统巡检」。读取审批预设及任务主机，可重复发起巡检，运行时每 7 秒轮询，关闭后停止。管理员可补充 Linux 主机 IP。 |
| 补丁流程操作记录 | 审计详情返回 `INSPECT` 时显示巡检步骤及其状态。 |

## 接口与语言

- 五个创建接口先调用 `change-control/check`。`PASS` 继续，`REJECT` 展示后端原因，`CONFIRM` 使用返回的短语。创建或执行接口返回 `NON_WINDOW_CONFIRM_REQUIRED` 时复核并重试同一个请求，保留原始用户输入。普通 400 提示保留后端原文。旧服务明确返回 404 或 405 时由创建接口做最终校验。
- 用户填写的实施时间按 Asia/Shanghai 转为毫秒时间戳。定时安装保持原有服务端时区字符串。审批的到期、预判和请求使用同一时区解释。
- 安装、回滚和真正的重启执行接入窗口复核。预检查、校验和跳过调用保留。Linux 流程识别预检查后已自动进入安装或回滚的状态，避免重新下发同一步。
- Axios 公共请求发送 `Language: zh-CN` 或 `Language: en`。初始化和切换语言同步同源 `NG_TRANSLATE_LANG_KEY` Cookie，供同源下载等非 Axios 请求使用。前端注册表继续启用简中和英文，并保留扩展字段。
- 已知任务状态、类型、窗口结果、审计键和巡检状态从后端语言包读取，中文静态动作通过后端字典反查；前端自有控件由现有中英文资源负责。用户申请说明、历史日志正文、巡检风险、原始主机名称及字典插值原样保留。漏洞界面的着色和操作条件优先读稳定状态字段。
