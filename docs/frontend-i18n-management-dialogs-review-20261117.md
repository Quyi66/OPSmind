## 确认并修复的问题

`BatchEditDialog.vue` 的校验规则在 setup 时固定了文案。真实页面复现：属性值失焦出现 Enter an attribute value 后，切换中文仍保留英文错误提示；切换回英文也不会重建规则。

改为 computed 生成规则，并接入已有 `useLocalizedValidation`：语言切换时只重新校验已经报错的字段。关闭规则变化时的整表自动校验，避免对未操作的属性选择字段新增错误。属性代码、输入草稿、选中的资产 ID、已加载模型和保存请求均保留；没有增加布局或 CSS 修改。

修复后的真实浏览器往返结果为：Enter an attribute value → 请输入属性值 → Enter an attribute value。两个回归用例分别验证已有错误翻译且不新增其他字段错误，以及保留草稿/模型/资产选择且不重新查询、不保存。
