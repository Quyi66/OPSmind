## 本批实现

扫描确认弹窗复用 `common.cancel`，新增 `selection.changeDevices`、`selection.startScan`。模板在渲染时翻译，不将翻译结果保存到选择状态。标题、描述仍由原调用页面传入，设备数组、确认事件、提交禁用和关闭保护保持原语义。

版本更新通知新增 `common.updateAvailable`、`common.updateAvailableDescription`。Element Plus 的通知标题参数是普通字符串，本批通过公开的函数消息插槽渲染标题和正文，使持久通知随语言变化重新渲染，避免关闭重开。样式仅限定在原有 `.update-notification` 内，隐藏空默认标题并保留标题与正文间距。原始版本 URL、build hash 比较、节流、轮询、停止检测和点击刷新逻辑保持。

生产修改涉及两个脚本/组件、一个通知样式文件和四个中英文词库文件；新增两个测试文件及本说明，另更新进度文档。本批没有修改之前四轮业务代码、已有词条或已写好的测试；进度文档是唯一与起点 49 个文件重叠的文件。
