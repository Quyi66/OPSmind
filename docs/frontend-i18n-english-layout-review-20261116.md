# 英文布局首批修复审查说明

- 分支：`feature/frontend-i18n`；已提交基线：`13692eca`。
- 本轮基于上一轮 5 个未提交文件继续，保留其实现和测试；本轮仍未暂存、未提交。
- 依据用户提供的英文主机概览截图，优先处理公共布局约束及截图对应的实际在用页面。

后续实现已按“英文修改不得影响中文排版”的要求完成[英文作用域收敛](./frontend-i18n-english-isolation-review-20261116.md)：恢复中文原有网格、断点、固定列宽和节点结构，布局修复仅对英文启用。下文保留首批实现与当时验证记录，其中关于两种语言共用新规则的说明不代表最新实现。

## 发现的问题与修改

| 问题 | 原因 | 本轮调整 |
| --- | --- | --- |
| 侧栏英文长名称被截断 | 公共侧栏固定 200px，嵌套缩进占用较多宽度，各层菜单项固定行高 | 英文展开侧栏增加到 256px，标题使用可收缩文本容器，按词换行并自适应行高；折叠仍沿用原有状态和尺寸 |
| 漏洞统计数字和说明相互挤压、被卡片裁剪 | 数字与人均说明强制单行，说明 `nowrap`；卡片列的最小宽度和比例按中文内容配置 | 卡片网格根据可用内容宽度自动换列，卡片允许收缩，标题/副标题及数字/说明可换行；影响人数与标签也允许分行 |
| 补丁图的英文轴标签空间不足 | 图表固定左侧 42px 且不计算标签尺寸 | 使用 ECharts 的 `containLabel` 计算轴标签空间；统计值、百分比和 tooltip 逻辑保持 |
| Important、Moderate 等表头从单词中间断开 | 主机严重程度列固定 80px，并继承表格的按字符换行 | 英文严重程度列使用更大的最小宽度；表头文字与圆点一起排列；主机表文本按词换行，较宽表格交由现有横向滚动承载 |
| Restart requirement 与操作列过窄、行内按钮堆叠 | 重启列固定 100px，固定操作列只有 130px | 英文重启列增加最小宽度，固定操作列为两个动作预留空间；动作使用独立可换行 flex 容器和明确间距 |
| 筛选/操作栏长标签、图标和按钮间距不协调 | 公共行内表单缺少完整的 flex 换行规则；部分标签宽度固定，按钮默认相邻 margin 与操作栏 gap 叠加 | 对英文 `.ops-filter-bar` 和 `.ops-action-bar` 增加换行、标签自动宽度、控件最大宽度、按钮图标间距；操作栏按钮允许随文案增高 |
| 同页漏洞明细仍有窄列 | 操作系统、系统版本、内核、扫描时间和操作列沿用中文固定列宽 | 英文模式分别调整最小宽度/固定操作列宽度，保留原列、状态值与操作事件 |

本轮公共修改仅覆盖菜单组件和标准筛选/操作栏，表格列宽修复限定在 Linux 主机概览、其实际复用的安装工作台及同页漏洞明细。没有通过全局改写表格布局模式、隐藏列或缩短业务字段来压缩内容。

统计卡片、Tab 换行和行内动作分组采用两种语言共用的自适应规则；侧栏扩展、公共筛选/操作栏规则及表格增宽按当前英文状态启用。公共顶部导航已有横向滚动规则，本轮没有改动其导航身份和权限逻辑。

## 状态与协议保护

- 不修改接口、查询结构、主机/补丁身份、严重程度协议值、权限和路由。
- 语言切换只调整展示和列宽；真实表格实例、勾选、分页及安装上下文继续使用原状态。
- 保留用户/后端的主机名、标签、操作系统值及原始错误正文。截图中的中文标签或用户名不能仅凭显示语言认定为翻译遗漏。
- 除共享进度文档外，上一轮的标签 Store 修复、两个联合测试和审查说明共 4 个文件与本轮起点逐字节一致。
