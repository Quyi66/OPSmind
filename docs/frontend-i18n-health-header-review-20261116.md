# 系统健康、资产总览与顶部导航布局审查

- 分支：`feature/frontend-i18n`。
- 本轮基线：`c1bb0cf4`，已提交前两组修改后的干净工作区。
- 依据：用户提供的系统健康、资产总览两张实际截图；同时调整顶部导航和语言切换位置。
- 交付语言仍为简体中文、英文，繁体仅保留扩展能力。无菜单且无实际调用的功能继续暂缓。

## 已完成的改动

### 系统健康

健康评分卡原先固定为 385px，评分标题、徽标、主机统计和运行信息按中文单行排列，英文内容会溢出到右卡。英文模式改为可收缩的比例双列，卡内标题、统计和运行信息支持换行；评分数值与 points 分行显示，减少圆环内挤压。1320px 以下使用单列，状态分布小卡根据可用内容宽度换列。

健康状态、评分、最近检查时间和固定操作列在英文下增加宽度，中文仍使用原有的 105/90/180/140px。风险文本按词换行；后端风险、主机名和作业消息保持原文。

入口为资产菜单 `/acm/hostHealthCheck` → `HostHealthCheckPage.vue` → `HostHealthSummaryBar.vue`。表格与评分规则、详情、执行链继续使用原处理逻辑。

### 资产总览

英文指标条使用自适应网格，标题预留一致高度，数值和说明分行排列，避免各项因英文长短产生不一致的基线。面板标题和操作区支持换行，操作图标与文字增加间距。

英文近期资产卡片使用至少 260px 的自适应列及至少 148px 的自动行高；Agent 状态和重启标记可换行，系统名称可显示多行。继续在原资产卡片视口中滚动，不更改分页容量计算、预览数据读取、当前资产类型或接口参数，避免因为切换语言重新拉取数据。

同时修正英文 `1 asset types`、`1 teams`，采用完整的单复数消息；简体词条和后端资产类型名称保持。

入口为 `/acm/overview` 的实际工作台和近期资产卡片，没有启用未使用的旧图表或历史页面。

### 顶部导航及语言入口

英文模式收紧菜单文字与间距；内容超出可用宽度时提供前后滚动按钮，按钮反映当前边界状态，活动菜单进入可视区域。尺寸观察器、语言和权限菜单变化会重新计算边界，卸载时释放监听。不隐藏或重新命名菜单，不更改权限或导航目标。

按用户明确要求，将中英文切换移至右侧工具区末端、主题按钮之后，并增加分隔间距。中英文使用同一位置，仍只有一个语言切换控件，保留原异步加载、失败回退及可访问标签。

其余导航布局优化仅在英文启用，中文菜单仍使用原有字号、间距和滚动方式。新增导航滚动按钮只在英文且内容溢出时出现。
