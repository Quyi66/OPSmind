# 设备选择流程浏览器验证记录

验证日期：2026-11-05。环境：用户当前已登录的本地前端 `https://localhost:5573/KoreOPS/`，连接原测试后端。通过实际页面点击功能入口、选择设备和确认按钮进行验证，没有替换后端响应。

## 本次修复

- Windows 扫描原先在整个后台执行周期保持 `submitting = true`，导致设备选择器持续显示遮罩、禁用关闭。现在只在提交请求期间锁定；请求返回后关闭选择器，有运行 ID 时打开可关闭的执行结果窗口，由独立观察器在任务结束后刷新列表。
- YUM 扫描和软件包扫描的提交状态也与后台观察分开，避免请求已返回但扫描入口不能重新打开。sudo 扫描提交后可关闭进度窗口，后台任务不会因此取消。
- 自定义视图原先把数组直接绑定到单个 `ElCheckbox`，不符合其属性类型。列表列与详情属性各使用一个 `ElCheckboxGroup` 管理选择数组。
