# 批量纳管 · 前端接口

前缀：`{网关}/cmdb/api/cmdb/agent`（与现有 CMDB 接口一致，带 `Authorization`、`Tenant-Id`）。
错误：HTTP 400，body `{message}`，直接提示 `message`。时间格式 `yyyy-MM-dd HH:mm:ss`（脚本接口的 `expiresAt` 除外，见 §5）。

| # | 方法 | 路径 | 用途 |
|---|---|---|---|
| 1 | POST | `/batches` | 新建批次并立即开始 |
| 2 | GET | `/batches` | 批次列表（最近 50 个） |
| 3 | GET | `/batches/{id}` | 批次详情（轮询用） |
| 4 | POST | `/batches/{id}/retry` | 重试失败项 |
| 5 | GET | `/batches/{id}/script?os=linux\|windows` | 批次脚本 |
| 6 | POST | `/batches/{id}/close` | 关闭批次 |

---

## 1. 新建批次 `POST /batches`

```json
{
  "name": "机房A 第一批",
  "hostIds": ["IMmtvf"],
  "targetText": "10.0.0.11-20, 10.0.0.0/28\n10.0.1.5",
  "targetOs": "linux",
  "targets": [{"ip": "10.0.2.8", "os": "windows", "hostname": "db-01"}],
  "groupId": null,
  "credentials": [
    {"os": "linux", "user": "ops", "password": "***", "becomePassword": "***", "port": 22},
    {"os": "windows", "user": "Administrator", "password": "***"}
  ],
  "keepCredentials": false
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `hostIds` / `targetText` / `targets` | 三选一或混用 | 已有资产 ID / 粘贴文本 / 逐台（Excel 导入时用） |
| `targetText` | | 换行、逗号、空格分隔；支持 `10.0.0.5`、`10.0.0.10-20`、`10.0.0.10-10.0.0.20`、`10.0.0.0/24`（掩码 /20~/32） |
| `targetOs` | | `targetText` 整段的 OS，`linux`（默认）/ `windows` |
| `name` | | 默认“批量纳管 yyyy-MM-dd HH:mm” |
| `groupId` | | 新 IP 建档放入的分组，默认根分组 |
| `credentials` | | 每种 OS 最多一组；**不填则该 OS 的机器全部走批次脚本** |
| `credentials[].authType` | | `password`（默认）/ `key`（用执行机 SSH 私钥，不传密码，仅 Linux） |
| `credentials[].port` | | 默认 Linux 22、Windows 5985 |
| `credentials[].becomePassword` | | Linux 非 root 时的 sudo 密码，默认同登录密码 |
| `credentials[].winrmTransport` / `winrmScheme` | | 默认 `ntlm` / `http`（端口 5986 时默认 `https`） |
| `keepCredentials` | | 默认 `false`：装完恢复资产原凭据；`true`：留作以后 SSH/WinRM 用 |

限制：单批最多 2000 台；任何一个 IP 不合法则整批 400、不建档。

返回：`BatchVO`（同 §3）。

## 2. 批次列表 `GET /batches`

返回 `BatchVO[]`，`items` 为空数组，只用 `batch` 和 `counts`。

## 3. 批次详情 `GET /batches/{id}`

```json
{
  "batch": {
    "id": "rp4xc7oNJB3rqG7CpxlY", "name": "机房A 第一批",
    "status": "open", "keepCredentials": 0,
    "expiresAt": "2026-11-14 12:27:09", "createdBy": "admin",
    "createdAt": "2026-11-13 12:27:09", "updatedAt": "2026-11-13 12:27:22"
  },
  "counts": {"online": 8, "unreachable": 1, "await_script": 3, "total": 12},
  "scriptOs": ["windows"],
  "items": [
    {
      "id": "wImIjIXm9mzPijfpSn0e", "hostId": "IMmtvf",
      "ip": "192.168.1.144", "hostname": "144", "targetOs": "linux",
      "channel": "push", "status": "online", "message": null,
      "clientId": "kops-66429f3f38a2",
      "createdAt": "2026-11-13 12:27:09", "updatedAt": "2026-11-13 12:27:22"
    }
  ]
}
```

- `batch.status`：`open` / `closed`。
- `counts`：键为下表的状态，另加 `total`；没有的状态不出现。
- `scriptOs`：还有哪些 OS 的机器没装上（为空时隐藏“批次脚本”按钮）。
- `items[].channel`：`push`（平台推装）/ `script`（批次脚本）。
- `items[].message`：失败原因或提示，原样展示。

**轮询**：每 5 秒请求一次；当 `counts` 中没有 `pushing` 和 `installed` 时停止。

### 状态

| status | 文案 | 颜色 | 行内操作 |
|---|---|---|---|
| `pushing` | 安装中 | 蓝 | — |
| `installed` | 等待上线 | 蓝 | — |
| `online` | 已上线 | 绿 | — |
| `auth_failed` | 凭据错误 | 红 | 可勾选重试 |
| `unreachable` | 网络不通 | 橙 | 可勾选重试；提示用批次脚本 |
| `install_failed` | 安装失败 | 红 | 可勾选重试 |
| `await_script` | 待脚本安装 | 灰 | 可勾选重试（需补凭据） |
| `conflict` | 需人工绑定 | 橙 | 链接到“待处理 Agent”页 |
| `skipped` | 已跳过 | 灰 | — |

## 4. 重试 `POST /batches/{id}/retry`

```json
{"itemIds": ["wImIjIXm9mzPijfpSn0e"], "credentials": [{"os": "linux", "user": "root", "password": "***"}]}
```

- `itemIds` 为空或不传：重试全部 `auth_failed` / `unreachable` / `install_failed` / `await_script`。
- `credentials` 同 §1；不传则用资产上现有凭据。
- 返回 `BatchVO`。没有可重试的主机、批次已关闭或已过期时返回 400。

## 5. 批次脚本 `GET /batches/{id}/script?os=windows`

```json
{
  "os": "windows",
  "installCommand": "powershell -NoProfile -ExecutionPolicy Bypass -Command \"...\"",
  "fileName": "koreops-agent-batch-install.cmd",
  "fileContent": "@echo off\r\n...",
  "maxUses": 3,
  "expiresAt": "2026-11-14T12:32:50.000+08:00"
}
```

- 页面提供两种用法：**复制命令**（`installCommand`）和**下载文件**（`fileContent` 存为 `fileName`；Linux 为 `.sh`）。
- `expiresAt` 是 ISO 8601 格式，展示时可直接用 `batch.expiresAt`。
- 每次调用都会签发一张新凭证，**只在用户点按钮时调用**，不要放进轮询。
- 提示语：Windows 需管理员执行；Linux 需 root 或 sudo；已装好的机器会自动跳过，可整批重复下发。

## 6. 关闭批次 `POST /batches/{id}/close`

吊销本批所有凭证。返回 `BatchVO`（`batch.status = closed`）。关闭后不能重试或取脚本，二次确认文案：“关闭后批次脚本立即失效，未上线的机器需新建批次”。

---

## 页面建议

1. **主机列表**：多选 →“批量安装 Agent”→ 弹窗按所选主机的 OS 显示凭据分组（Linux / Windows，都可留空）→ `POST /batches { hostIds, credentials }` → 跳转批次详情。
2. **批量纳管页 · 新建**：名称、IP 文本框 + OS 单选（或导入 Excel 转 `targets`）、分组、凭据分组、“保留凭据”开关。
3. **批量纳管页 · 列表**：名称、状态、进度条（`online / total`）、创建人、创建时间。
4. **批次详情**：顶部计数条 + 操作按钮（重试失败项、批次脚本、关闭批次）；下方逐台表格（IP、主机名、OS、通道、状态、说明），可按状态筛选、勾选后重试。
