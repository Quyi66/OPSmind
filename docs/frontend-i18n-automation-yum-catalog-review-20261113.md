# 自动化、Yum 与补丁清单中英文改造审查说明

本轮以 `feature/frontend-i18n`、`0e8b8d43` 和继续任务时的工作区代码为基础，代码保留在工作区，没有暂存或提交。此前首页、个人资料、资产与 AI 的未提交修改继续保留。本文件描述本轮增量，不能直接把相对 `HEAD` 的全部差异视作本轮修改。

交付语言为简体中文和英文。繁体中文保持未启用的扩展预留；后端直接返回的中文、用户输入、文件正文、命令、日志和自定义名称不翻译。

## 状态与接口边界

- 本地静态文案在模板、computed、getter 中求值。持续显示的读取错误、预览提示和缺省标题保存消息 key 与参数，切换语言后更新显示。
- 已填的工具/流程/仓库草稿、主机/文件/命令选择、Cron/Quartz 表达式、频道展开状态、筛选、分页和打开的详情保留。语言切换不重新请求业务列表、详情或提交操作，不改变原轮询与 WebSocket 通道。
- 对内置标题和本地缺省标题的搜索，执行搜索时保存显示名称快照，避免换语言后已匹配的结果消失。显式重新搜索或重新读取数据时使用当前语言名称。
- 流程排序保留原来源名称与稳定排序值。任务操作使用原调度 ID，工具 ID、运行 ID、文件路径、仓库 ID、厂商/OS/架构值及状态码不改写。
- 已安装软件的 `可升级`、返回数据中的 `启用`、`未启用`、`无` 等仍用于原接口参数或业务判断；仅前端标签翻译。后端字段显示仍可按约定保留中文。
- 表单关闭自动规则变更校验，只重新验证原本已有错误的字段来更新提示；没有操作过的字段不因换语言报错。
- 软件主机操作的异步完成提示在回调执行时读取当前语言。统计图保留计数、无效数据留空语义和排行；实际 ECharts 合并新语言选项时保留已操作的缩放范围。
- 文件、CSV、脚本、CURL 与命令正文不送入词条编译器，`{{参数}}`、`${参数}` 和 `$basearch` 等技术语法保持。导出优先保留服务器文件名，仅缺省文件名随语言变化。
- 补丁库上传反馈使用 Vue 文本节点展示后端消息及失败文件名，不拼接为 HTML；原上传文件、请求体和操作流程保持。

新增 `automation`、`yumRepo`、`patches` 命名空间，仅接入两个启用语言。公共 `messageRef` 补充了支持 `null` 和本地消息对象的类型说明，保持原运行时逻辑。旧词库补充实际回归使用的 `jao.title`、查看/复制别名；未知历史 key 继续既有简体兜底，不假定全部历史字典已经完成英文迁移。

## 独立审查方式

本轮与上一轮会共享语言入口、公共词库、严重程度显示函数和进度文档，因此不是完全不同的文件集合。共享文件在保留旧工作区内容的基础上叠加本轮修改，资产、首页和 AI 的既有实现不回退。

对任务开始时保存的 105 个已有未提交文件核对：99 个保持字节不变，另外 6 个是上述共享文件，没有文件丢失。公共词库原有 key 的值保持，新增显示词条不替换旧业务字段。

当前工作区的独立增量保存在本地忽略目录中：

- `.cache/i18n-automation-yum-catalog-review.patch`：相对于本轮开始时工作区的增量，包含本轮新增文件。
- `.cache/i18n-automation-yum-catalog-review-files.json`：本轮文件清单及最终内容 SHA-256。
- `.cache/i18n-auto-start/manifest.json`：本轮开始时已有未提交文件的基线摘要。

这些文件用于本机审查，不作为产品源码提交。不要对当前工作区直接应用该补丁；当前代码已经包含其变更。此前资产与 AI 的审查补丁没有重新生成。
