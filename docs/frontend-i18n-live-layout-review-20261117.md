本轮以 `feature/frontend-i18n` 的 `b068d7adaa8ec2df9b6046ed0497fdc7c7c6e030` 为比较基线。审查通过后，浏览器巡检工具及 Vite 缓存监听修复提交为 `0a07f849`，英文布局、审查修复及对应组件测试提交为 `c831b9d2`。当前交付仍为简体中文与英文，保留语言注册扩展；后端返回的中文、用户命名、日志和业务正文不翻译。

## 真实页面的采集方式与范围

桌面控制接口和旧调试端口的连接问题，已通过独立 Playwright Chrome 会话解决。使用用户手动登录的专用资料访问本地开发服务，沿当前账号的实际菜单发现页面，不再依赖逐页人工截图。未复制日常浏览器资料，未绕过 HTTPS 校验，未执行生产构建。

菜单清单包含首页及当前权限下的 60 个实际菜单目的地。每页按简体中文、英文和 1440 / 1920 CSS 像素窗口宽度采集；同时检查设备清单、分组/标签、连接模板和参数页面的已审查只读标签，以及宽表格的横向隐藏列。固定列占用的宽度计入滚动步长，避免漏掉中间字段。

另外沿实际入口查看系统健康评分规则、Windows 主机补丁抽屉及 KB 详情、Linux 主机详情的三个标签、顶部用户菜单、个人资料及空密码表单、平台用户资料、团队/资产/巡检模板的未保存表单，以及巡检报告的主机、检查项和导出字段预览。对健康、资产、Windows 补丁和主机用户概览补充 1280 / 2160 宽度的英文复查。仅打开、切换标签、滚动和关闭；未输入或保存表单，未执行扫描、安装、审批、删除、发送邮件或业务导出。

已注册但无菜单且无系统内调用的功能继续暂缓。本轮没有通过手输 URL 将这些功能重新纳入范围。

## 中文保护与验证

新增的布局分支通过 `currentLocale === 'en-US'`、组件英文标记或 `html[lang='en-US']` 生效。中文继续使用原列宽、输入宽度、网格和断点；没有改动简体中文词库。标签栏在中文状态下继续采用原有的窗口缩放处理。

本地检查将中文模板分支与基线比较，并在编译样式后去除英文规则核对默认 CSS。静态比较不替代真实中文页面的人工验收；接口数据会随时间变化，也未将不同时间的截图做像素等同比较。

首轮真实页面复核的定向回归按测试文件去重汇总为 **92 个文件、977 项用例通过**，另有巡检工具 **11 项 Node 用例通过**。词库检查为 **2 种语言、各 5003 个 key、8022 处静态引用通过**。当时 39 个 Vue/SCSS 文件的中文模板及默认样式与基线一致；36 个业务组件的 112 处 API 调用签名与参数无变化。46 个源文件的静态检查包含 38 个 Vue 组件解析/模板编译，未增加 ESLint 错误；既有 28 处错误按基线保留，没有将“无新增错误”表述为全仓库零错误。`git diff --check` 通过，未运行生产构建。后续审查修复另记如下。

## 审查意见修复

- 标签栏的英文 resize 改为等待连续事件结束 100ms 后检查，当前标签仍完整可见时保留用户滚动位置；不可见时才调用原定位逻辑。无论是否移动都更新箭头。切换语言及卸载时取消等待中的 resize，中文 resize 继续立即更新箭头。语言切换和路由导航的定位行为保留。
- 审批时长统一通过展示函数处理：英文将非空数字字符串转为有限非负数后选择复数，异常值使用原有空值占位；不修改后端记录、筛选或请求。中文继续把原始值传给原词条，包括 `02` 这样的字符串格式。设备选择数量仍使用数组长度，其他命名空间的同名 key 不受影响。
- 文件输入下方已有中英文允许目录说明，Windows 概览也已声明 SCSS，这两处没有新增修复。

本次定向回归 **4 个文件、20 项用例通过**，覆盖实际滚动视口的左右裁切、可见标签不移动、连续 resize 合并、箭头双向更新、中文行为、语言切换及卸载取消等待，以及两个审批页面的字符串数量、异常值、中文原值和不重复查询。50 个源文件静态检查（含 39 个 Vue 组件）无新增 ESLint 错误，112 处 API 调用签名与参数无变化；词库及 `git diff --check` 通过。
