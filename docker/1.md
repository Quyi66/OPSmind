只需创建一个新的 compose overlay 文件。以新增一个 预发布环境 192.168.1.200 为例：

1. 创建 override 文件
在 docker/ 目录下新建 docker-compose.<环境名>.yml，例如：

# docker/docker-compose.staging.yml
version: '3'
services:
  opsmind-web:
    environment:
      - BACKEND_URL=http://192.168.1.200:8080
      - SSL_DOMAINS=192.168.1.200,localhost
只需要写差异部分，其他配置自动继承自 
docker-compose.yml
。

2. 启动命令
docker-compose -f docker-compose.yml -f docker-compose.staging.yml up -d
3. SSL_DOMAINS 的写法规则
场景	SSL_DOMAINS 值
仅 IP 访问	192.168.1.200,localhost
仅域名访问	staging.ops.com,localhost
IP + 域名都要	staging.ops.com,192.168.1.200,localhost
多个域名	ops.com,www.ops.com,192.168.1.200
逗号分隔即可，脚本会自动识别 IP 和 DNS 并正确写入证书的 SAN 字段。
